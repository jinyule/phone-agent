# Normalization class of every numeric and id field a fixture can hold (engineering-baseline §3.2).
# Columns: <scope> <path> <leaf type> <class>. NormalizedFieldsTest fails when the serializers
# can write a field that is missing here, or a line names a field that no longer exists; its
# failure writes the full current list to core/build/replay/normalized-fields.actual.txt.
#
# Scopes: header (line 1 of session.jsonl), envelope (a record line without its data), an event
# type (that record's data), requests (a line of requests.expected.jsonl).
# Paths: name, name[] (each element), {sub} (that sealed subtype), * (each map value).
#
# Classes:
#   time      wall-clock time, set to 0                        (N1)
#   expiry    absolute deadline, kept relative to record time  (N2)
#   duration  jittered wait, set to 0                          (N3)
#   task, session, call, prompt
#             id replaced by {{kind:n}}, numbered by first occurrence in the log  (N4)
#   kept      id that replay reproduces as is (snapshot, element, blob, provider, model)
#   seq       a seq or a reference to one, kept
#   value     any other number (sizes, counts, coordinates, amounts, versions), kept
