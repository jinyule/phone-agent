必须写全：
1. 用户的目标、约束和偏好，只写现在还有效的：关键的话照原话引用，不用把用户说过的话全部照抄；用户撤回或改过的要求，写明已撤回或改成了什么。数字、金额、时间、人名、联系人和 App 名一字不改。
2. 已经做过的步骤和结果，以屏幕上看到的为准。这几类要单独标出来：发出的消息、提交的订单、完成的付款这类不能重做的对外动作；失败的、被系统或用户拒绝的动作；结果不确定的动作（写明“不确定”，不要写成成功）。

4. 还没了结的事：等用户确认或回答的问题，接下来打算做的一步。用户的回答照原样写；用户的确认和拒绝，写明针对的是哪个动作、对象、金额和条件。

- 摘要里记下的确认不是新的授权：之后再遇到系统要求确认、交给用户处理或拒绝，照当时的要求办，不能拿以前的确认代替。
